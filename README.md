# The Full Deck — Website

The website for **The Full Deck**, a party card game: a deck of drinking and party games for every table.

## Pages

- `index.html`: landing page introducing the deck, with a sign-up form
- `111.html`: the deck itself, where you browse the cards and their rules
- `privacy.html`: terms and privacy

It's a plain static site (HTML, CSS and a little JavaScript) with no build step.

## Hosting

The site is hosted on [Netlify](https://www.netlify.com/). This repo holds the source only; GitHub Pages is not used.
